Gộp file thuộc tính gCadas (.gtp)

Chọn các file đang dùng và các file dữ liệu cũ, mỗi bên một hoặc nhiều tờ. Công cụ đưa toàn bộ thửa của file cũ còn thiếu sang file đang dùng, kèm chủ sử dụng, giấy tờ, đơn đăng ký, mục đích sử dụng, thửa cũ và trang sổ địa chính. File gốc không bị sửa. Mọi xử lý chạy ngay trên máy, không gửi dữ liệu đi đâu.

① File đang dùng · ưu tiên
    Chọn hoặc kéo thả một hay nhiều file (mỗi tờ một file). File đứng trên được ưu tiên nếu trùng thửa.
    ② File cũ
      Chọn hoặc kéo thả một hay nhiều file cũ. Thửa chỉ có ở file cũ được thêm đầy đủ.
      Không trùngSo khớp theo số tờ + số thửa. Thửa đã có trong file đang dùng thì không thêm lần nữa.
      Không thiếuThửa chỉ có ở một file được đưa vào đầy đủ cùng mọi hồ sơ liên quan, đánh lại mã nội bộ để không đè dữ liệu.
      Có biên bảnLiệt kê thửa thêm mới, trường được bổ sung và các chỗ hai file ghi khác nhau để kiểm tra lại.
      Chọn đủ hai file để bắt đầu.
      Hỗ trợ file thuộc tính gCadas dạng .gtp (có mã hoá hoặc không). Kết quả được kiểm tra toàn vẹn trước khi tải về. Sau khi gộp, nên mở file trong gCadas cùng bản đồ tương ứng và chạy lại kiểm tra topology.
